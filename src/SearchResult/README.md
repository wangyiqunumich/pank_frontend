# SearchResult JS Map

## Schema result (URL params: sourceTerm/relationship/targetTerm)

- index.js: Old UI + schema flow.
- index_new.js: New UI + schema flow (ResultComponent layout).

## Agent result (URL param: question)

- resultpage.js: Old UI + agent flow.
- resultpage_new.js: New UI + agent flow (ResultComponent layout).

## Layout/tooling

- AgentResult.js: Layout wrapper (disabled bottom search bar, optional multi-result).
- loading.js: Loading overlay component used by result pages.
- result.js: Export alias for resultpage.js.
